# AT5 Tutor — MUF0152 Contemporary Issues 2

Study site for the AT5 academic discussion (Rwanda 1994 & Russia–Ukraine War).

- 8 assessed questions: word-by-word breakdown, model spoken answers, evidence, push-back replies, A4 lines
- Evidence bank checked against the assigned readings, with oral citations
- Speaking timer with 1-minute prep and recording, unseen question drill
- Flashcards, quiz, media bias types, timelines, discussion phrases, printable A4 sheet

Static site: open `index.html`, or serve with GitHub Pages (Settings → Pages → Deploy from branch `main`, folder `/`).
Progress and notes are saved in your browser only.
